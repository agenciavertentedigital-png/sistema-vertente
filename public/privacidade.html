Vertente Digital · Sistema Vertente

Política de Privacidade

Última atualização: 1 de novembro de 2026

O Sistema Vertente é a ferramenta interna da agência Vertente Digital para gestão de clientes, tarefas e desempenho de campanhas. É usado apenas pela equipe da agência.

Dados que acessamos

  • Dados de login da equipe (nome e e-mail).
  • Dados de campanhas de anúncios das contas que os clientes da agência autorizaram (Google Ads e Meta Ads): investimento, impressões, cliques, conversões e status das contas.
  • Informações cadastradas pela equipe sobre os clientes (briefings, tarefas, anotações).

Uso dos dados do Google

O acesso à API do Google Ads é somente leitura e serve exclusivamente para gerar relatórios de desempenho para os clientes da agência. Os dados não são vendidos, compartilhados com terceiros nem usados para publicidade. O uso das informações recebidas das APIs do Google segue a Política de Dados do Usuário dos Serviços de API do Google, incluindo os requisitos de Uso Limitado.

Armazenamento e segurança

Os dados ficam em banco de dados com acesso restrito à equipe autenticada. Chaves e tokens de acesso são guardados criptografados e nunca são exibidos.

Seus direitos (LGPD)

Você pode pedir acesso, correção ou exclusão dos seus dados e revogar a autorização do Google a qualquer momento em myaccount.google.com/permissions. Basta escrever para o e-mail abaixo.
